# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Email **yauhen.bichel@gmail.com** with:

- what the issue is and roughly how severe you think it is
- the steps to reproduce it
- the affected version or commit

You can expect an acknowledgement within a few days. Once the issue is confirmed and fixed I will
credit you in the release notes, unless you would rather stay anonymous.

## Scope

This is a portfolio and learning project, not a hosted service — there is no production deployment
to attack. Reports about the code itself (injection, dependency vulnerabilities, leaked
credentials in the history) are all in scope and welcome.

## Credentials

If you find a credential, API key or token committed anywhere in this repository or its history,
please report it privately by email rather than opening an issue.
